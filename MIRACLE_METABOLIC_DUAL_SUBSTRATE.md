# Miracle Meta Memory / Metabolic Memory / Dual-Substrate Architecture
Derived from: CANONICAL_ARCHITECTURE.md

## Three distinct governance layers

### Miracle Meta Memory
Governed continuity and durable memory lifecycle.

### Metabolic Memory v2
Resource governance over memory state. It manages pressure and residency, not authority.

### Dual Substrate Authority
Independent governance/evidence evaluation before Kernel convergence.

These systems interact but are not interchangeable.

## Memory lifecycle

```
INGEST
 -> CLASSIFY
 -> PROVENANCE
 -> STORE
 -> RETRIEVE
 -> UPDATE
 -> QUARANTINE when required
 -> SNAPSHOT
 -> RECOVER
```

Metabolic governance runs as a resource-control loop over eligible active memory.

## Metabolic lifecycle

```
FIELD STEP
 -> PHYSICS / DECAY
 -> QUARANTINE CLEANUP
 -> ACTIVE SET
 -> RATE CALCULATION
 -> FLUX DEMAND
 -> RESERVOIR GENERATION
 -> CAPACITY CHECK
 -> EVICTION
 -> RESIDUAL CHECK
 -> LEDGER
```

Subsidy lifecycle:

```
REQUEST
 -> SOURCE VALIDATION
 -> TARGET VALIDATION
 -> APPROVAL / RATIFICATION GATE
 -> RESERVOIR CHECK
 -> TRANSFER
 -> LEDGER
```

## Authority separation

Miracle Meta Memory cannot authorize.

Metabolic Memory cannot authorize.

Substrate A cannot authorize.

Substrate B cannot authorize.

Only Engine 3 / Convertible Cranium Kernel creates canonical authority.
