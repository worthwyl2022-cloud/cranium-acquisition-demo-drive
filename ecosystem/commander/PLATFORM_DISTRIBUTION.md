# Cranium Command — Platform Distribution

Cranium Command is one client surface delivered through three compatible targets:

1. **PC / laptop boot media** — the Linux appliance remains the computer-native distribution surface.
2. **Android APK** — a native WebView shell packages the same Commander web client for phones and tablets.
3. **Installable Web/PWA** — modern browsers can install the same Commander client as an app-like experience.

The Android package is not a claim that a normal Android phone can boot the PC ISO. Android devices use a separate application/runtime path. Optional device-specific boot experimentation can be evaluated later for unlocked devices without changing the primary distribution model.

The authority boundary is unchanged across targets: Commander → Cranium AI → Synapse evidence → Cranium Kernel canonical authority → governed execution → Miracle Memory, with COMA and the Session Circuit Breaker providing containment and recovery.

The UI is never the canonical authority source.
