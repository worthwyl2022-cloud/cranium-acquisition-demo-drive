# Legacy Cranium Substrate Archive

This directory preserves the historical `cranium_substrate` prototype and its benchmark/export artifacts for provenance and historical reference.

It is **not** the authoritative Cranium implementation and is not part of the production authority path.

The authoritative authority source is the canonical `cranium-kernel` lineage. Historical prototype measurements and prototype contradiction/NLI implementations must not be presented as current production evidence.

Archive purpose:
- preserve prior implementation history without deleting intellectual work;
- keep obsolete prototype code out of production source paths;
- prevent stale generated exports from being bundled into WorthWyl Forge;
- maintain a clear boundary between historical evidence and current canonical implementation.
